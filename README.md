# Student Registration System (PHP)

A simple student registration project built with **PHP** (and MySQL if configured). It allows adding and managing student records.

## Features
- Student registration form
- Insert data into database
- Basic PHP form handling

## Tech Stack
PHP • MySQL • HTML • CSS

## Setup (Local)
1. Install **XAMPP/WAMP**
2. Copy the project folder to:
   - XAMPP: `htdocs/`
3. Start **Apache** (and **MySQL** if using database)
4. Create a database (example): `student_reg` (use your own name)
5. Update database settings in `connection.php`:
   - host: `localhost`
   - username: `root`
   - password: `""`
   - database name: (your DB name)
6. Open in browser:
   `http://localhost/student_reg/`

## Notes
- DB password is empty by default for local XAMPP (`root` + empty password).
